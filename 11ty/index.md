# Welcome to Planning Poker

Remote estimation for distributed software teams.

## What is Planning Poker?

Planning Poker is a web application that enables distributed software teams to run estimation sessions remotely with:

- Real-time synchronization using CRDT technology
- Anonymous voting to reduce anchoring bias
- Peer-to-peer communication with no backend required
- In-browser session persistence and export

## Features

### Session Management
- Create or join rooms with shareable links
- No account signup required
- Multiple roles: facilitator, voter, observer

### Estimation
- Use Fibonacci card deck plus special cards
- Anonymous voting rounds
- Facilitator-controlled reveal
- Multiple rounds per item with discussion

### Collaboration
- Real-time participant updates
- Live voting status
- Vote distribution visualization
- Session history and export

## Getting Started

1. **Create a Room** - Facilitator creates a new planning session
2. **Invite Team Members** - Share the room link with your team
3. **Add Items** - Populate backlog items to estimate
4. **Run Rounds** - Vote, reveal, discuss, and revote
5. **Finalize** - Save estimates and export session data
